# Bem Sertanejo FM

Site institucional de página única feito com React, TypeScript, Vite e Tailwind CSS.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Use `pnpm build` para gerar `dist/` e `pnpm preview` para conferir o build localmente. Consulte o [guia de publicação na HostGator](docs/deploy-hostgator.md) para configurar o domínio, o SSL e o endpoint PHP.
